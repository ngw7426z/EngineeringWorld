Memory Fabric: HBM Die-to-Die Interconnect for GPU Bandwidth Expansion

여러 HBM 메모리 스택을 GPU 패키지 안에서 직접 연결하는 ‘Memory Fabric’ 구조를 제안한 연구입니다. 연산 칩을 거치지 않고 메모리끼리 데이터를 주고받게 해, 대규모 AI 연산에서 메모리 대역폭 병목을 줄이는 방법을 보여줍니다.

이 연구가 중요한 이유 컴퓨터 성능은 프로세서뿐 아니라 메모리와 데이터 이동 구조에도 크게 좌우된다는 점을 보여줍니다.
