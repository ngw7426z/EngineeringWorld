Engineering World - 33개 공학 분야 프리미엄 확장판

업데이트 내용
- 기존 6개에서 총 33개 공학 분야로 확장
- 분야 검색, 분야별 분류 필터, 결과 개수, 검색어 지우기, 전체 보기 제공
- 카드 UI를 그라데이션, 입체 그림자, 호버 효과가 있는 프리미엄 디자인으로 변경
- 33개 모두 개별 상세 페이지 연결
- 기존 메인 화면, 소개/능력/퀴즈/진로 페이지와 스크롤 애니메이션 유지

GitHub 적용
1. ZIP 압축을 풉니다.
2. GitHub EngineeringWorld 저장소 > Code > Add file > Upload files
3. 압축을 푼 폴더 안의 파일 전체를 업로드합니다. ZIP이나 폴더 자체를 업로드하지 마세요.
4. 기존 파일은 덮어쓰고 새 파일도 모두 추가합니다.
5. Commit changes를 누르고 Pages 배포 후 Ctrl+F5로 새로고침합니다.

중요 파일
- fields.html: 33개 분야 탐색 화면
- fields-extra.css: 새 분야 페이지의 화려한 디자인
- field-detail.css: 각 분야 상세 페이지 디자인
- site.js: 검색/필터/스크롤 애니메이션 기능
- 새 분야별 HTML 상세 페이지 27개 추가

모든 파일을 저장소 최상위(root)에 두세요. index.html과 fields.html이 최상위에 있어야 합니다.
