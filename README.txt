Engineering World - 스크롤 애니메이션 + 검색 기능 추가본

추가된 기능
1. 메인 및 부가 페이지에서 스크롤에 따라 점선 배경과 원형 장식이 움직입니다.
2. 페이지의 섹션과 카드가 화면에 나타날 때 부드럽게 올라오는 애니메이션이 적용됩니다.
3. fields.html에 공학 분야 검색창이 추가되었습니다.
   - 컴퓨터, 로봇, 전기전자, 건축, 자동차, 항공우주 등 검색 가능
   - 검색 결과가 없을 때 안내 문구 표시

설치 방법
1. ZIP 압축을 풉니다.
2. 기존 GitHub 저장소에 있는 파일들을 이 압축파일의 파일로 교체합니다.
3. 새 파일 site.js도 저장소에 업로드합니다.
4. GitHub Pages 배포가 끝나면 웹사이트를 새로고침합니다.

주의
- HTML/CSS 파일 이름과 폴더 구조를 유지하세요.
- 브라우저 캐시 때문에 바로 반영되지 않으면 Ctrl + F5로 강력 새로고침하세요.
