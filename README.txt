Engineering World - 스크롤 애니메이션 + 검색 기능 업데이트

기능
- 메인과 부가 페이지: 스크롤에 반응하는 점선/원 장식, 섹션과 카드 등장 애니메이션
- 공학 분야 페이지(fields.html): 분야 검색 및 검색 결과 없음 안내

GitHub에 업데이트하는 방법
1. 이 ZIP을 내려받고 압축을 풉니다.
2. GitHub에서 EngineeringWorld 저장소의 Code 화면을 엽니다.
3. Add file > Upload files를 누릅니다.
4. 압축을 푼 폴더 안의 파일 전체를 선택해 업로드합니다. 폴더 자체나 ZIP만 올리지 마세요.
5. 기존 파일과 이름이 같은 파일은 반드시 교체되도록 업로드하고, site.js 새 파일도 올립니다.
6. Commit changes를 눌러 저장합니다.
7. Pages 배포 후 웹사이트에서 Ctrl+F5로 새로고침합니다.

확인
- fields.html에서 site.js 연결을 포함하도록 수정했습니다.
- 모든 HTML 페이지가 같은 site.js를 불러오도록 확인했습니다.
- 파일명과 폴더 구조를 변경하지 마세요.
