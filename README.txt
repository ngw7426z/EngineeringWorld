Engineering World - 전체 페이지 프리미엄 디자인 + 33개 최신 연구 요약판

이번 업데이트
1. 공학 분야 페이지에서 사용한 보라·청록 그라데이션, 점선/원형 장식, 입체 카드 디자인을 전체 페이지에 확장했습니다.
2. 홈, 공학이란?, 필요한 능력, 공학 퀴즈, 나의 진로, 33개 공학 상세 페이지의 공통 디자인을 통일했습니다.
3. 33개 공학 상세 페이지마다 2026년 공개된 관련 연구 논문 1편의 요약을 추가했습니다.
   - 논문 제목, 학술지, 공개 시기, 핵심 내용, 연구의 의미, DOI 링크 포함
4. 홈 화면의 공학 분야 개수도 33개로 맞췄습니다.
5. 기존 검색, 카테고리 필터, 스크롤 애니메이션, 퀴즈 기능은 유지했습니다.

논문 요약 관련 안내
- 2026년 11월 7일 기준으로 웹에서 확인 가능한 2026년 논문 중 해당 분야와 관련성이 높은 사례를 선정했습니다.
- 요약은 공개된 초록과 서지정보를 바탕으로 쉽게 풀어 쓴 것이며, 논문 전문 전체를 번역/검토한 것은 아닙니다.
- 분야별로 더 새로운 논문이 추가 공개될 수 있으므로 최신성은 계속 갱신이 필요합니다.

GitHub 적용 방법
1. ZIP 압축을 풉니다.
2. GitHub의 EngineeringWorld 저장소 > Code > Add file > Upload files로 이동합니다.
3. 압축을 푼 폴더 안의 파일을 모두 업로드합니다. ZIP 파일이나 폴더 자체를 올리지 마세요.
4. 기존 파일은 덮어쓰고 새 CSS/HTML 파일도 추가합니다.
5. Commit changes를 누릅니다.
6. GitHub Pages 배포 후 Ctrl+F5로 강력 새로고침합니다.

중요
- site-theme.css 파일을 반드시 업로드해야 전체 공통 디자인이 적용됩니다.
- field-detail.css에는 연구 요약 카드 디자인이 포함되어 있습니다.
- 33개 상세 HTML 페이지가 모두 필요합니다.
- 모든 파일을 저장소 최상위(root)에 두세요. index.html과 fields.html이 최상위에 있어야 합니다.
